# VT-Morse-Trainer

**An Android application for learning and practicing Morse code reception.**

VT Morse Trainer is designed to help users improve their Morse code reception skills, recognize character groups and practice accurate message decoding.

## Features

- Morse code training with letters and numbers
- Reception and checking of Morse code groups
- Answer input by typing
- Voice-based answers using the NATO phonetic alphabet
- Adjustable training speed
- Optional interference during exercises
- Immediate feedback on answers

## Purpose

The aim of VT Morse Trainer is to provide an accessible and practical tool for learning, practicing and maintaining Morse code skills.

The application is under continuous development.
